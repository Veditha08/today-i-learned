# DSA Notes

## Time Complexity
- O(1) Constant
- O(log n) Logarithmic - Binary Search
- O(n) Linear
- O(n log n) Merge Sort, Heap Sort
- O(n^2) Bubble Sort, Selection Sort
- O(2^n) Backtracking

## Space Complexity
Always consider auxiliary space alongside time complexity.
Memory-time tradeoff is a key consideration.
