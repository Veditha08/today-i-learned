# Object Oriented Programming

## Four Pillars

Encapsulation:
- Bundle data and methods together
- Control access with public/private/protected

Abstraction:
- Hide implementation details
- Expose only necessary interface

Inheritance:
- Child class inherits parent properties and methods
- Promotes code reuse
- IS-A relationship

Polymorphism:
- Same method name, different behavior
- Method overriding (runtime)
- Method overloading (compile time)

## SOLID Principles
S - Single Responsibility: one class, one reason to change
O - Open/Closed: open for extension, closed for modification
L - Liskov Substitution: subtypes must be substitutable for base types
I - Interface Segregation: clients should not depend on unused interfaces
D - Dependency Inversion: depend on abstractions, not concretions
