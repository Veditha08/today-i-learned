# Interview Preparation Guide

## Technical Interview Approach
1. Clarify the problem and constraints
2. Work through examples (happy path + edge cases)
3. Think aloud - share your thought process
4. Start with brute force approach
5. Optimize step by step
6. Code cleanly with good variable names
7. Test with examples and edge cases
8. Analyze time and space complexity

## Problem Solving Framework
Understand -> Plan -> Code -> Test -> Optimize

## Topics Priority
High Priority:
- Arrays, Strings, HashMaps
- Trees (BST, traversals)
- Graphs (BFS, DFS)
- Dynamic Programming (top 15 patterns)
- Recursion and Backtracking

Medium Priority:
- Linked Lists
- Stack and Queue
- Heaps
- Binary Search
- Greedy algorithms

## Behavioral Questions (STAR)
Situation - Task - Action - Result
Prepare 5-6 solid stories covering:
- Conflict resolution
- Leadership
- Technical challenge solved
- Failure and learning
- Working under pressure

## Quick Revision Checklist

Data Structures:
- Arrays, Strings
- Linked List (singly, doubly, circular)
- Stack, Queue, Deque
- Trees: BST, AVL, Heap, Trie
- Graph: adjacency list/matrix
- Hash Map, Hash Set

Algorithms:
- Sorting: merge, quick, heap
- Searching: binary search variants
- Graph: BFS, DFS, Dijkstra, Kruskal
- DP: knapsack, LCS, LIS, coin change
- Backtracking: subsets, permutations

CS Fundamentals:
- OS: processes vs threads, deadlock, scheduling
- DBMS: ACID, transactions, normalization, indexing
- Networks: HTTP, TCP/IP, DNS, TLS
- System Design: scalability, caching, load balancing, CAP

Keep practicing! Consistency > intensity.
