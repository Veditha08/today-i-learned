# Computer Networking

## OSI Model (7 Layers)
7. Application: HTTP, DNS, SMTP, FTP
6. Presentation: encryption, encoding
5. Session: manage connections
4. Transport: TCP, UDP, port numbers
3. Network: IP addressing, routing
2. Data Link: MAC addresses, frames
1. Physical: cables, signals, bits

## TCP vs UDP
TCP: reliable, ordered, connection-oriented
Use for: HTTP, email, file transfer

UDP: fast, unreliable, connectionless
Use for: video streaming, gaming, DNS, VoIP

## HTTP/HTTPS
HTTP: HyperText Transfer Protocol (port 80)
HTTPS: HTTP + TLS encryption (port 443)
HTTP/2: multiplexing, header compression
HTTP/3: QUIC protocol (UDP-based)

## DNS Resolution
Browser cache -> OS cache -> Router cache
-> ISP resolver -> Root server -> TLD -> Authoritative DNS
